# 🐛 Reporting issues

[Public documentation](README.md)

Use the [Issues tab](https://github.com/CoC-MS/ALSO-Microsoft-Security-Windows/issues) to report a problem with this repository's Windows exports or documentation. Search existing issues first.

Include the package, workload, exact filename or policy name, relevant Windows version and enrollment context, import steps, and expected versus actual behavior. Remove or redact environment-specific information.

> [!IMPORTANT]
> Public issues are visible to everyone. Do not attach tenant exports, credentials, tokens, certificates or private keys, customer details, tenant or device identifiers, assignments, or unredacted logs and screenshots.

Do not report exploitable vulnerabilities or sensitive security details in a public issue. Use GitHub private vulnerability reporting if available for this repository, or an established private disclosure channel.
